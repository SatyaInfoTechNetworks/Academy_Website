# Fix for Google Sheets Data Not Showing

The script you are using expects "Form Data", but our website sends "JSON Data". That is why only the Date (generated by the script) is showing up.

Please replace **everything** in your Google Apps Script with this code. This code is specifically designed to read the JSON data sent by your website.

## Step 1: Copy this Code
```javascript
function doPost(e) {
  // Get the active sheet
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  
  // Parse the JSON data sent from the website
  var data = JSON.parse(e.postData.contents);
  
  // Append the row in the correct order
  sheet.appendRow([
    data.date,
    data.name,
    data.email,
    data.phone,
    data.transactionId,
    data.course,
    data.amount,
    data.promoCode
  ]);
  
  // Return success message
  return ContentService.createTextOutput(JSON.stringify({"status":"success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## Step 2: Update the Script
1. Go to your Google Sheet -> **Extensions** -> **Apps Script**.
2. **Delete everything** currently in the file.
3. **Paste** the code above.
4. Click **Save** (Floppy disk icon).

## Step 3: Publish New Version (CRITICAL)
1. Click **Deploy** -> **Manage deployments**.
2. Click the **Pencil Icon** (Edit) next to your current deployment.
3. **Version**: Select **New version**. (Do not skip this!)
4. Click **Deploy**.

Now try submitting the form again. The data will appear!
